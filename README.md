# Intro

This project is part of my course work for creativa's graduation project.

We were asked to analyze the data, make some visualizations, extract all useful information, then recommend the suitable next steps.

# Installation
1. Clone the repo:
```bash
git clone https://github.com/AnasElgamed8/Grocery-Orders-Analysis.git
cd Grocery-Orders-Analysis
# Download deps
uv sync
```
2. Download and extract the [data](https://drive.google.com/drive/folders/1RaoujBxvuV9JGqYYKax9oxRREtgddB-z?usp=sharing)
3. Place it in a folder called 'data' in project root.
4. run `uv run marimo view src/notebook.py`

Or run the jupyter notebook directly.
